Each card is a statement from [Theory](theory.md). Each labelled arrow is a proof, running from the results it uses to the result it proves. Click a card to show its statement and highlight its proofs; click it again to fold it, or use **Statements** to show them all. Click a proof to see what it uses. Drag to rearrange, scroll or pinch to zoom, and double-click a card to open it in the notes.

## Blocks

Cards (Nodes) in these graphs are `:::theorem`, `:::definition` and other blocks.

Directed edges are produced by `:::proof` blocks like

```markdown
:::proof[Theorem 1.53]{#prf-FA-from-IVT proves="#def-fundamental-axiom" uses="#thm-IVT"}
See Theorem 1.53 of the book.
:::
```

which create an edge pointing into node `#def-fundamental-axiom` from each of the nodes in `uses`.

A proof with several `uses` premises draws a line from each premise to the proof's label, and a single arrow from the label to the `proves` node.

## Interactive
Clicking a card expands its statement and opens its relationships.

- `PROVED BY` in edges
- `USED IN` out edges
- `HIGHLIGHT` dims everything except direct neighbours, all upstream, or all downstream results

## Trivial Example

### The Blocks

From [Theory Graph Example](theory_graph_example.md):

```markdown
:::definition[Even]{#def-even}
$n \in \mathbb{Z}$ is even if $n = 2j$ for some $j \in \mathbb{Z}$.
:::

:::definition[Odd]{#def-odd}
$n \in \mathbb{Z}$ is odd if $n = 2k + 1$ for some $k \in \mathbb{Z}$.
:::

:::theorem[Even plus odd]{#thm-even-plus-odd}
If $m$ is even and $n$ is odd, then $m + n$ is odd.
:::

:::proof[Add the forms]{proves="#thm-even-plus-odd" uses="#def-even #def-odd"}
$m + n = 2j + (2k + 1) = 2(j + k) + 1$.
:::
```
