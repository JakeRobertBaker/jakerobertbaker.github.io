## Blocks

Cards (Nodes) in these graphs are `:::theorem`, `:::definition` and other blocks.

Directed edges are produced by labelled `:::proof` blocks like `Add the forms`, which create an edge pointing into node `#thm-even-plus-odd` from each of the nodes in `uses`.

A proof with several `uses` premises draws a line from each premise to the proof's label, and a single arrow from the label to the `proves` node.

### Example

From [Theory Graph Example](theory_graph_example.md):

```markdown
:::definition[Even]{#def-even}
$n \in \mathbb{Z}$ is even if $n = 2j$ for some $j \in \mathbb{Z}$.
:::

:::definition[Odd]{#def-odd}
$n \in \mathbb{Z}$ is odd if $n = 2k + 1$ for some $k \in \mathbb{Z}$.
:::

:::theorem[Even plus odd]{#thm-even-plus-odd}
If $m$ is even and $n$ is odd, then $m + n$ is odd.
:::

:::proof[Add the forms]{proves="#thm-even-plus-odd" uses="#def-even #def-odd"}
$m + n = 2j + (2k + 1) = 2(j + k) + 1$.
:::
```

One proof using two premises: both lines meet at the *Add the forms* label, and one arrow leaves it.

## Interactive
Clicking a card expands its statement and opens its relationships.

- `PROVED BY` in edges
- `USED IN` out edges
- `HIGHLIGHT` dims everything except direct neighbours, all upstream, or all downstream results

## Graph Object
You can specify the pages or single blocks (e.g. `'theory.md#thm-IVT'`) to include. The graph below is produced by
