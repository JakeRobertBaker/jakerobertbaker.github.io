Permutations and Combinations

Section titled “Permutations and Combinations”

Consider a size nnn set AAA.

A size r≤nr \leq nr≤n permutation is a length rrr tuple (a1,…,ar)(a_1,\dots,a_r)(a1​,…,ar​) where each ai∈Aa_i \in Aai​∈A appears exactly once. In other words a permutation is a size rrr sample without replacement.

A size rrr combination is length rrr subset of AAA.

There are

n×(n−1)×⋯×(n−r+1)=n!(n−r)!n \times (n-1) \times \dots \times (n-r+1) = \frac{n!}{(n-r)!}n×(n−1)×⋯×(n−r+1)=(n−r)!n!​

size rrr permutations.

Any size rrr tuple maps to size rrr combination via

(a1,…,ar)↦{a1,…,ar}.(a_1,\dots,a_r) \mapsto \{a_1,\dots,a_r\}.(a1​,…,ar​)↦{a1​,…,ar​}.

There are r!r!r! possible permutations that map to combination {a1,…,ar}\{a_1,\dots,a_r\}{a1​,…,ar​}.

Hence there are

(nr)≔n!r!(n−r)!\binom{n}{r} \coloneqq \frac{n!}{r!(n-r)!}(rn​):=r!(n−r)!n!​

possible size rrr combinations.
