Section titled “Question”

Prove that if AAA and BBB are subsets of R\mathbb{R}R and ∣B∣=0|B| = 0∣B∣=0, then ∣A∪B∣=∣A∣|A \cup B| = |A|∣A∪B∣=∣A∣.

Section titled “Solution”

Proof.

We show both inequalities.

(i) ∣A∪B∣≤∣A∣|A \cup B| \leq |A|∣A∪B∣≤∣A∣:

∑k=1∞ℓ(Ik)<ε.\sum_{k=1}^{\infty} \ell(I_k) < \varepsilon.k=1∑∞​ℓ(Ik​)<ε.

A∪B⊆(⋃i=1∞Gi)∪(⋃k=1∞Ik),A \cup B \subseteq \left(\bigcup_{i=1}^{\infty} G_i\right) \cup \left(\bigcup_{k=1}^{\infty} I_k\right),A∪B⊆(i=1⋃∞​Gi​)∪(k=1⋃∞​Ik​),

Question

Section titled “Question”

Suppose FFF is a subset of R\mathbb{R}R with the property that every open cover of FFF has a finite subcover. Prove that FFF is closed and bounded.

Solution

Section titled “Solution”

Key idea: If a set is not closed, it is missing a limit point xxx. Build an open cover of FFF that nibbles toward xxx but never reaches it, so any finite subcover leaves out a ball around xxx — contradicting the existence of points of FFF arbitrarily close to xxx.

Definition · Limit Point#

A limit point of a set F⊆RF \subseteq \mathbb{R}F⊆R is a point x∈Rx \in \mathbb{R}x∈R such that for every ε>0\varepsilon > 0ε>0, there exists y∈Fy \in Fy∈F with 0<∣x−y∣<ε0 < |x - y| < \varepsilon0<∣x−y∣<ε. A set is closed if and only if it contains all its limit points (Supplement for MIRA).

Proof.

FFF is closed:

Suppose for contradiction that FFF is not closed. Then there exists a limit point xxx of FFF with x∉Fx \notin Fx∈/F. For each n∈Z+n \in \mathbb{Z}^+n∈Z+, define

Gn={y∈R:∣x−y∣>1n}.G_n = \left\{y \in \mathbb{R} : |x - y| > \tfrac{1}{n}\right\}.Gn​={y∈R:∣x−y∣>n1​}.

Each GnG_nGn​ is open (it is the union of the two open rays (−∞,x−1n)(-\infty, x - \tfrac{1}{n})(−∞,x−n1​) and (x+1n,∞)(x + \tfrac{1}{n}, \infty)(x+n1​,∞)). We claim {Gn}n=1∞\{G_n\}_{n=1}^{\infty}{Gn​}n=1∞​ is an open cover of FFF. Indeed, let y∈Fy \in Fy∈F. Since x∉Fx \notin Fx∈/F, we have y≠xy \neq xy=x, so ∣x−y∣>0|x - y| > 0∣x−y∣>0. Choose nnn large enough that 1n<∣x−y∣\tfrac{1}{n} < |x - y|n1​<∣x−y∣. Then y∈Gny \in G_ny∈Gn​. Hence

F⊆⋃n=1∞Gn.F \subseteq \bigcup_{n=1}^{\infty} G_n.F⊆n=1⋃∞​Gn​.

By hypothesis, there exists a finite subcover. Since G1⊆G2⊆⋯G_1 \subseteq G_2 \subseteq \cdotsG1​⊆G2​⊆⋯, any finite subcollection {Gn1,…,GnM}\{G_{n_1}, \ldots, G_{n_M}\}{Gn1​​,…,GnM​​} satisfies

⋃k=1MGnk=GN,where N=max⁡(n1,…,nM).\bigcup_{k=1}^{M} G_{n_k} = G_N, \quad \text{where } N = \max(n_1, \ldots, n_M).k=1⋃M​Gnk​​=GN​,where N=max(n1​,…,nM​).

So F⊆GN={y∈R:∣x−y∣>1N}F \subseteq G_N = \{y \in \mathbb{R} : |x - y| > \tfrac{1}{N}\}F⊆GN​={y∈R:∣x−y∣>N1​}. But xxx is a limit point of FFF, so there exists y∈Fy \in Fy∈F with 0<∣x−y∣<1N0 < |x - y| < \tfrac{1}{N}0<∣x−y∣<N1​, meaning y∉GNy \notin G_Ny∈/GN​. This contradicts F⊆GNF \subseteq G_NF⊆GN​. Therefore FFF is closed.

FFF is bounded:

The collection {(−k,k)}k=1∞\{(-k, k)\}_{k=1}^{\infty}{(−k,k)}k=1∞​ is an open cover of FFF, since F⊆R=⋃k=1∞(−k,k)F \subseteq \mathbb{R} = \bigcup_{k=1}^{\infty}(-k, k)F⊆R=⋃k=1∞​(−k,k). By hypothesis, there exists a finite subcover. Since (−1,1)⊆(−2,2)⊆⋯(-1, 1) \subseteq (-2, 2) \subseteq \cdots(−1,1)⊆(−2,2)⊆⋯, the union of any finite subcollection equals the largest interval in that subcollection. Hence there exists N∈Z+N \in \mathbb{Z}^+N∈Z+ such that F⊆(−N,N)F \subseteq (-N, N)F⊆(−N,N). Therefore FFF is bounded. ■\blacksquare■

where the strict inequality holds because c<bc < bc<b. Hence ∣(a,b)∪(c,d)∣≠(b−a)+(d−c)|(a,b) \cup (c,d)| \neq (b-a) + (d-c)∣(a,b)∪(c,d)∣=(b−a)+(d−c).

∣(a,b)∪(c,d)∣<(b−a)+(d−c).|(a,b) \cup (c,d)| < (b-a) + (d-c).∣(a,b)∪(c,d)∣<(b−a)+(d−c).
