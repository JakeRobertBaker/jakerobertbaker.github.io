Definition · Standard Normal Vector#

A random vector z∈Rn\mathbf{z} \in \mathbb{R^n}z∈Rn is standard normal iff components (zi)i=1n(\mathbf{z_i})_{i=1}^n(zi​)i=1n​ are independantly identically distributed N(0,In)\mathcal{N}(\mathbf{0,I_n})N(0,In​).

Note

If a vector in standard normal w.r.t one basis then it is standard normal w.r.t any basis.

Definition · OLS#

An ordinary least squares linear model (OLM) provides an estimate β^\hat{\beta}β^​ of unknown coefficent β∈Rp×1\beta \in \mathbb{R^{p \times 1}}β∈Rp×1 to the problem,

We assume that εσ\dfrac{\varepsilon}{\sigma}σε​ is standard normal (Definition) ⇔ε∼N(0,σ2In)\Leftrightarrow \varepsilon \sim \mathcal{N}(\mathbf{0, \sigma^2 I_n})⇔ε∼N(0,σ2In​), where we may not know σ\sigmaσ.

Theorem · Solution of OLS#

Assume that X\mathbf{X}X has full rank.

The solution of OLS is given by β^=(XTX)−1XTy\hat{\beta} = \mathbf{(X^TX)^{-1}X^Ty}β^​=(XTX)−1XTy.
