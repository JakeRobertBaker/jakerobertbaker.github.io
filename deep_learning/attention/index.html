Attention Definition

Section titled “Attention Definition”

Let Query, Key and Value Matricies be Q:(T,Dk)\mathbf{Q}:(T,D_k)Q:(T,Dk​), K:(S,Dk)\mathbf{K}:(S,D_k)K:(S,Dk​) and V:(S,Dv)\mathbf{V}:(S,D_v)V:(S,Dv​). We also let T∈NT \in \mathbb{N}T∈N denote a sequence length not neccessarily equal to S∈NS \in \mathbb{N}S∈N.

Definition · Attention#

Attention:(T,Dk)×(S,Dk)×(S,Dv)→(T,Dv)\text{Attention}: (T,D_k) \times (S,D_k) \times (S,D_v) \to (T,D_v)Attention:(T,Dk​)×(S,Dk​)×(S,Dv​)→(T,Dv​) maps

Explanation

Section titled “Explanation”

Write the matricies as,

Q=[q1T⋮qTT]K=[k1T⋮kST]V=[v1T⋮vST]\mathbf{Q}= \begin{bmatrix} \mathbf{q_1^T} \\ \vdots \\ \mathbf{q_T^T} \end{bmatrix} \mathbf{K}= \begin{bmatrix} \mathbf{k_1^T} \\ \vdots \\ \mathbf{k_S^T} \end{bmatrix} \mathbf{V}= \begin{bmatrix} \mathbf{v_1^T} \\ \vdots \\ \mathbf{v_S^T} \end{bmatrix}Q=​q1T​⋮qTT​​​K=​k1T​⋮kST​​​V=​v1T​⋮vST​​​

for qi,kj∈RDk,vj∈RDv,i=1,...,T,j=1,...,S\mathbf{q_i, k_j} \in \mathbb{R}^{D_k}, \mathbf{v_j} \in \mathbb{R}^{D_v}, i=1,...,T, j=1,...,Sqi​,kj​∈RDk​,vj​∈RDv​,i=1,...,T,j=1,...,S

We see that Zi,j≔1DkQKTi,j=1Dkqi⋅kj\mathbf{Z}_{i,j}\coloneqq \frac{1}{\sqrt{D_{k}}} \mathbf{QK^T}_{i,j} = \frac{1}{\sqrt{D_k}} \mathbf{q_i \cdotp k_j}Zi,j​:=Dk​​1​QKTi,j​=Dk​​1​qi​⋅kj​ is like a similarity score between query iii and key jjj.

Compatibility Function

Section titled “Compatibility Function”

If we observe the softmax applied to Z\mathbf{Z}Z, we see that each element is a compatibility function, α\alphaα, between query iii and key jjj.

σ(Z)i,j=exp⁡(Zi,j)∑r=1Sexp⁡(Zi,r)=exp⁡(1Dkqi⋅kj)∑r=1Sexp⁡(1Dkqi⋅kr)=score(i,j)∑r=1Sscore(i,r)≕α(qi,K,j)\begin{align*} \sigma \left( \mathbf{Z} \right)_{i,j} &= \cfrac{ \exp \left( \mathbf{Z}_{i,j} \right) } {\sum_{r=1}^S \exp \left( \mathbf{Z}_{i,r} \right) } \\ &= \cfrac{ \exp \left( \frac{1}{\sqrt{D_k}} \mathbf{q_i \cdotp k_j} \right) } {\sum_{r=1}^S \exp \left( \frac{1}{\sqrt{D_k}} \mathbf{q_i \cdotp k_r} \right) } \\ &= \cfrac{\text{score}(i,j)}{\sum_{r=1}^S \text{score}(i,r)} \eqqcolon \alpha(\mathbf{q_i},\mathbf{K},j) \end{align*}σ(Z)i,j​​=∑r=1S​exp(Zi,r​)exp(Zi,j​)​=∑r=1S​exp(Dk​​1​qi​⋅kr​)exp(Dk​​1​qi​⋅kj​)​=∑r=1S​score(i,r)score(i,j)​=:α(qi​,K,j)​

Let A≔Attention(Q,K,V)\mathbf{A} \coloneqq \text{Attention}(\mathbf{Q,K,V})A:=Attention(Q,K,V), then

Ai,j=∑r=1Sσ(Z)i,rVr,j=∑r=1Sα(qi,K,r)[vr]j  ⟹  rowi(A)=∑r=1Sα(qi,K,r)vrT∈R1,Dv\begin{align*} \mathbf{A}_{i,j} = \sum_{r=1}^S \sigma \left( \mathbf{Z} \right)_{i,r} \mathbf{V}_{r,j} &= \sum_{r=1}^S \alpha(\mathbf{q_i},\mathbf{K},r) [\mathbf{v_r}]_j \\ \implies \text{row}_i \left( \mathbf{A} \right) &= \sum_{r=1}^S \alpha(\mathbf{q_i},\mathbf{K},r) \mathbf{v_r^T} \in \mathbb{R}^{1,D_v} \end{align*}Ai,j​=r=1∑S​σ(Z)i,r​Vr,j​⟹rowi​(A)​=r=1∑S​α(qi​,K,r)[vr​]j​=r=1∑S​α(qi​,K,r)vrT​∈R1,Dv​​

row iii of A\mathbf{A}A is the sum of values, each weighted by query iii's similarity with that key.

Remarks

Section titled “Remarks”

Attention is permutation invariant

Notice that row iii of A\mathbf{A}A is a function of qi,K,V\mathbf{q_i, K,V}qi​,K,V,

rowi(A)=∑r=1Sα(qi,K,r)vrT≕f(qi,K,V)\text{row}_i \left( \mathbf{A} \right) = \sum_{r=1}^S \alpha(\mathbf{q_i},\mathbf{K},r) \mathbf{v_r^T} \eqqcolon f(\mathbf{q_i, K,V})rowi​(A)=r=1∑S​α(qi​,K,r)vrT​=:f(qi​,K,V)

Therefore if we permute two rows of Q\mathbf{Q}Q, the output of Attention has the same two rows of A\mathbf{A}A permuted.
