Stage 2 — Encoder Stack (repeated N=6N = 6N=6 times)

Section titled “Stage 2 — Encoder Stack (repeated N=6N = 6N=6 times)”

Each encoder layer applies two sub-layers with a residual connection and LayerNorm around each. LayerNormRes\text{LayerNormRes}LayerNormRes is either:

LayerNormRespost(x,Sub)=LayerNorm(x+Sub(x))LayerNormRespre(x,Sub)=Sub(LayerNorm(x))+x\text{LayerNormRes}_{\text{post}}(\mathbf{x}, \text{Sub}) = \text{LayerNorm}(\mathbf{x} + \text{Sub}(\mathbf{x})) \\ \text{LayerNormRes}_{\text{pre}}(\mathbf{x}, \text{Sub}) = \text{Sub}(\text{LayerNorm}(\mathbf{x})) + \mathbf{x}LayerNormRespost​(x,Sub)=LayerNorm(x+Sub(x))LayerNormRespre​(x,Sub)=Sub(LayerNorm(x))+x

The original paper uses post-norm; pre-norm (used in my code) has been found to train more stably. A single encoder layer E\mathbf{E}E is:

Where MHA\text{MHA}MHA is defined in Attention Mechanism and FFN\text{FFN}FFN is defined below.

FFN(x)=ϕ ⁣(xW1+b1)W2+b2\text{FFN}(\mathbf{x}) = \phi\!\left(\mathbf{x}\mathbf{W}_1 + \mathbf{b}_1\right)\mathbf{W}_2 + \mathbf{b}_2FFN(x)=ϕ(xW1​+b1​)W2​+b2​

ϕ\phiϕ is the activation function, W1:(D=512, Dff=2048)\mathbf{W}_1 : (D{=}512,\, D_{ff}{=}2048)W1​:(D=512,Dff​=2048) and W2:(Dff=2048, D=512)\mathbf{W}_2 : (D_{ff}{=}2048,\, D{=}512)W2​:(Dff​=2048,D=512). There are N=6N=6N=6 encoder layers E1,…,EN\mathbf{E}_1, \ldots, \mathbf{E}_NE1​,…,EN​, each with independent parameters. The output of one layer is the input to the next.

M1=E1(X~src)⋮Mi=Ei(Mi−1)⋮M=MN=EN(MN−1):(S=5, D=512)\mathbf{M}_1 = \mathbf{E}_1(\tilde{\mathbf{X}}_{\text{src}}) \\ \vdots \\ \mathbf{M}_i = \mathbf{E}_i(\mathbf{M}_{i-1}) \\ \vdots \\ \mathbf{M} = \mathbf{M}_N = \mathbf{E}_N(\mathbf{M}_{N-1}) : (S{=}5,\, D{=}512)M1​=E1​(X~src​)⋮Mi​=Ei​(Mi−1​)⋮M=MN​=EN​(MN−1​):(S=5,D=512)

Because of MHA M\mathbf{M}M is like a context-aware representation of every source token, informed by all other source tokens. It is passed unchanged into every one of the NNN decoder layers.

Remark — what the self-attention is comparing#

Let's consider the first layer of the stack.

MHA ⁣(X~src,  X~src,  X~src):(S=5, D=512)\text{MHA}\!\left(\tilde{\mathbf{X}}_{\text{src}},\; \tilde{\mathbf{X}}_{\text{src}},\; \tilde{\mathbf{X}}_{\text{src}}\right) : (S{=}5,\, D{=}512)MHA(X~src​,X~src​,X~src​):(S=5,D=512)

All three of Q,K,V\mathbf{Q}, \mathbf{K}, \mathbf{V}Q,K,V are projections of the same matrix X~src\tilde{\mathbf{X}}_{\text{src}}X~src​, so Zi,j=qi⋅kj\mathbf{Z}_{i,j} = \mathbf{q}_i \cdot \mathbf{k}_jZi,j​=qi​⋅kj​ measures how much source token iii attends to source token jjj. For example, token i=LOVELYi = \text{LOVELY}i=LOVELY may learn to attend strongly to token j=TODAYj = \text{TODAY}j=TODAY, capturing their syntactic relationship. Output row iii is:

rowi(A)=∑r=1Sα(qi,K,r)  vrT\text{row}_i(\mathbf{A}) = \sum_{r=1}^{S} \alpha(\mathbf{q}_i, \mathbf{K}, r)\; \mathbf{v}_r^Trowi​(A)=r=1∑S​α(qi​,K,r)vrT​

a blend of all S=5S=5S=5 source value vectors, weighted by relevance to source position iii.

Definition · Padding Mask#

A padding mask zeros out attention for any padding token.

σ(QKT)i,j\sigma \left( \mathbf{QK^T} \right)_{i,j}σ(QKT)i,j​ is set to zero whenever query iii or key jjj's token correspond to padding. Usually this is done via setting QKTi,j\mathbf{QK^T}_{i,j}QKTi,j​ to negative infinity.

Equivalently, σ(Z)i,j=σ(QKTDk)i,j=α(qi,K,j)=0\sigma \left(\mathbf{Z} \right)_{i,j} = \sigma \left( \frac{\mathbf{QK^T}}{\sqrt{D_k}} \right)_{i,j} = \alpha(\mathbf{q}_i, \mathbf{K}, j)=0σ(Z)i,j​=σ(Dk​​QKT​)i,j​=α(qi​,K,j)=0 when iii or jjj represent padding.

Note, this is not needed here since S=5S = 5S=5 with no padding, but applied in batched training.

Stage 3 — Target Embedding + Positional Encoding (Training)

Section titled “Stage 3 — Target Embedding + Positional Encoding (Training)”

During training the full target sentence is known. The decoder is fed a shifted-right version of the target — prepending a special beginning-of-sequence token ⟨BOS⟩\langle\text{BOS}\rangle⟨BOS⟩ and dropping the final token:

Target labels (what we predict):Ytgt=[LETEMPSESTMAGNIFIQUE](T=4)\textbf{Target labels (what we predict):} \quad \mathbf{Y}_{\text{tgt}} = \begin{bmatrix} \text{LE} \\ \text{TEMPS} \\ \text{EST} \\ \text{MAGNIFIQUE} \end{bmatrix} \quad (T = 4)Target labels (what we predict):Ytgt​=​LETEMPSESTMAGNIFIQUE​​(T=4) Decoder input (shifted right):Xtgt=[⟨BOS⟩LETEMPSEST](T=4)\textbf{Decoder input (shifted right):} \quad \mathbf{X}_{\text{tgt}} = \begin{bmatrix} \langle\text{BOS}\rangle \\ \text{LE} \\ \text{TEMPS} \\ \text{EST} \end{bmatrix} \quad (T = 4)Decoder input (shifted right):Xtgt​=​⟨BOS⟩LETEMPSEST​​(T=4)
Remark — why shift right#

The shift means: the decoder at position iii must predict target token i+1i+1i+1 using only the tokens at positions 1,…,i1, \ldots, i1,…,i. Seeing ⟨BOS⟩\langle\text{BOS}\rangle⟨BOS⟩ it should predict LE; seeing ⟨BOS⟩\langle\text{BOS}\rangle⟨BOS⟩, LE it should predict TEMPS; and so on. This is teacher forcing — the ground-truth tokens are fed in as input rather than the model's own previous predictions.

These T=4T=4T=4 shifted-right tokens are embedded and position-encoded in the same way as the source:

X~tgt=Xtgt+PEtgt:(T=4, D=512)\tilde{\mathbf{X}}_{\text{tgt}} = \mathbf{X}_{\text{tgt}} + PE_{\text{tgt}} : (T{=}4,\, D{=}512)X~tgt​=Xtgt​+PEtgt​:(T=4,D=512)

Stage 4 — Decoder Stack (repeated N=6N = 6N=6 times)

Section titled “Stage 4 — Decoder Stack (repeated N=6N = 6N=6 times)”

Each decoder layer has three sub-layers, each wrapped with a residual connection and LayerNorm (as in Stage 2). A single decoder layer D\mathbf{D}D is:

DL1(x)=LayerNormRes ⁣(x,  MaskedMHA):(T,D)DL2(x,M)=LayerNormRes ⁣(x,  CrossMHA( ⋅ , M, M)):(T,D)DL3(x)=LayerNormRes ⁣(x,  FFN):(T,D)D(x,M)=DL3(DL2(DL1(x),M)):(T,D)\mathbf{DL_1}(\mathbf{x}) = \text{LayerNormRes}\!\left(\mathbf{x},\; \text{MaskedMHA} \right) : (T, D) \\[6pt] \mathbf{DL_2}(\mathbf{x,M}) = \text{LayerNormRes}\!\left(\mathbf{x},\; \text{CrossMHA}(\,\cdot\,,\, \mathbf{M},\, \mathbf{M}) \right) : (T, D) \\[6pt] \mathbf{DL_3}(\mathbf{x}) = \text{LayerNormRes}\!\left(\mathbf{x},\; \text{FFN} \right) : (T, D) \\[6pt] \mathbf{D}(\mathbf{x,M}) = \mathbf{DL_3}(\mathbf{DL_2}(\mathbf{DL_1}(\mathbf{x}), \mathbf{M})) : (T, D)DL1​(x)=LayerNormRes(x,MaskedMHA):(T,D)DL2​(x,M)=LayerNormRes(x,CrossMHA(⋅,M,M)):(T,D)DL3​(x)=LayerNormRes(x,FFN):(T,D)D(x,M)=DL3​(DL2​(DL1​(x),M)):(T,D)

There are N=6N=6N=6 decoder layers D1,…,DN\mathbf{D}_1, \ldots, \mathbf{D}_ND1​,…,DN​, each with independent parameters. As with the encoder, the output of one layer is the input to the next. The encoder output M\mathbf{M}M is passed unchanged into every decoder layer's cross-attention sub-layer.

G1=D1(X~tgt)⋮Gi=Di(Gi−1)⋮G=GN=DN(GN−1):(T,D)\mathbf{G}_1 = \mathbf{D}_1(\tilde{\mathbf{X}}_{\text{tgt}}) \\ \vdots \\ \mathbf{G}_i = \mathbf{D}_i(\mathbf{G}_{i-1}) \\ \vdots \\ \mathbf{G} = \mathbf{G}_N = \mathbf{D}_N(\mathbf{G}_{N-1}) : (T, D)G1​=D1​(X~tgt​)⋮Gi​=Di​(Gi−1​)⋮G=GN​=DN​(GN−1​):(T,D)

Sub-layer 1 — Masked Decoder Self-Attention

Section titled “Sub-layer 1 — Masked Decoder Self-Attention”
Definition · Causal (Look-Ahead) Mask#

All entries with j>ij > ij>i in the T×T=4×4T \times T = 4 \times 4T×T=4×4 score matrix Z\mathbf{Z}Z are set to −∞-\infty−∞ before the softmax.

Therefore the attention weights become zero, α(qi,K,r)=0\alpha\left( \mathbf{q}_i, \mathbf{K},r \right)=0α(qi​,K,r)=0 for all r>ir>ir>i.

Therefore, the weighted sum of values is restricted to positions up to and including iii.

rowi(A)=∑r=1iα(qi,K,r)  vrT\text{row}_i(\mathbf{A}) = \sum_{r=1}^{i} \alpha(\mathbf{q}_i, \mathbf{K}, r)\; \mathbf{v}_r^Trowi​(A)=r=1∑i​α(qi​,K,r)vrT​

This preserves the autoregressive property: position iii can only depend on positions 1,…,i1, \ldots, i1,…,i.

Causal masked multi head attention measures how much the decoder representation of token iii attends to token jjj for j≤ij \leq ij≤i.

For example, when i=ESTi = \text{EST}i=EST (position 4), the model can attend to ⟨BOS⟩\langle\text{BOS}\rangle⟨BOS⟩, LE, TEMPS, and EST itself — but not to any later position.

The paper says:

self-attention layers in the decoder allow each position in the decoder to attend to all positions in the decoder up to and including that position.

In practise the Masked Decoder MHA sublayer recieves a representation of the decoding x=X~tgt\mathbf{x} = \mathbf{\tilde{X}}_{\text{tgt}}x=X~tgt​ or Gi,\mathbf{G}_i,Gi​, for i∈{1,…,N−1}i \in \left\{ 1, \dots, N - 1 \right\}i∈{1,…,N−1} after the residual connection and LayerNorm:

g(1)=LayerNormRes(x,  MaskedMHA):(T,D)\mathbf{g}^{(1)} = \text{LayerNormRes}(\mathbf{x},\; \text{MaskedMHA}) : (T, D)g(1)=LayerNormRes(x,MaskedMHA):(T,D)

Sub-layer 2 — Encoder–Decoder Cross-Attention

Section titled “Sub-layer 2 — Encoder–Decoder Cross-Attention”
MHA ⁣(g(1)⏟Q : (T=4,  D=512),    M⏟K : (S=5,  D=512),    M⏟V : (S=5,  D=512)):(T,D)\text{MHA}\!\left( \underbrace{\mathbf{g}^{(1)}}_{Q\,:\,(T{=}4,\;D{=}512)},\;\; \underbrace{\mathbf{M}}_{K\,:\,(S{=}5,\;D{=}512)},\;\; \underbrace{\mathbf{M}}_{V\,:\,(S{=}5,\;D{=}512)} \right) : (T, D)MHA​Q:(T=4,D=512)g(1)​​,K:(S=5,D=512)M​​,V:(S=5,D=512)M​​​:(T,D)

Here the queries come from the decoder's current representation g(1)\mathbf{g}^{(1)}g(1) and the keys/values come from the encoder's final output M\mathbf{M}M. The score matrix is T×S=4×5T \times S = 4 \times 5T×S=4×5 — each of the T=4T=4T=4 target positions attends over all S=5S=5S=5 source positions.

No causal mask is applied here — the decoder is free to attend to any source position when generating any target position. A padding mask is applied to suppress attention to any padded source positions.

Remark — what the cross-attention is comparing#

The similarity Zi,j=qi⋅kj\mathbf{Z}_{i,j} = \mathbf{q}_i \cdot \mathbf{k}_jZi,j​=qi​⋅kj​ measures how much target token iii attends to source token jjj.

For example when generating Ytgt\mathbf{Y}_{\text{tgt}}Ytgt​ every query representing Xtgt\mathbf{X}_{\text{tgt}}Xtgt​ is allowed attend to all keys representing source Xtgt\mathbf{X}_{\text{tgt}}Xtgt​

rowi(A)=∑r=1Sα(qi,K,r)  vrT\text{row}_i(\mathbf{A}) = \sum_{r=1}^{S} \alpha(\mathbf{q}_i, \mathbf{K}, r)\; \mathbf{v}_r^Trowi​(A)=r=1∑S​α(qi​,K,r)vrT​

For example when trying to generate i=4i=4i=4 target MAGNIFIQUE the query q4\mathbf{q}_4q4​ for (shifted right target) EST is allowed to attend to all English states.

After the residual connection and LayerNorm:

g(2)=LayerNormRes(g(1),  CrossMHA):(T,D)\mathbf{g}^{(2)} = \text{LayerNormRes}(\mathbf{g}^{(1)},\; \text{CrossMHA}) : (T, D)g(2)=LayerNormRes(g(1),CrossMHA):(T,D)

Stage 5 — Linear Projection + Softmax

Section titled “Stage 5 — Linear Projection + Softmax”

The decoder output G\mathbf{G}G is projected into vocabulary space and passed through a softmax to produce a predicted probability distribution over the vocabulary at each position:

P^=softmax ⁣(G WO):(T, ∣V∣)\hat{\mathbf{P}} = \text{softmax}\!\left(\mathbf{G}\,\mathbf{W}_O\right) : (T,\, |\mathcal{V}|)P^=softmax(GWO​):(T,∣V∣)

where WO:(D, ∣V∣)\mathbf{W}_O : (D,\, |\mathcal{V}|)WO​:(D,∣V∣) is a learned linear projection. Row iii of P^\hat{\mathbf{P}}P^ is the model's predicted probability distribution over all vocabulary tokens for target position iii.

Remark — weight tying#

The paper shares the same weight matrix between the two embedding layers (source and target) and the pre-softmax linear transformation WO\mathbf{W}_OWO​. In the embedding layers the weights are multiplied by D\sqrt{D}D​.

Remember that due to the shifted-right decoder input, the predictions align as:

Xtgt=[⟨BOS⟩LETEMPSEST]⏞Decoder Input Position  ⇒  [LETEMPSESTMAGNIFIQUE]⏞Model Predicts=Ytgt\mathbf{X}_{\text{tgt}} = \overbrace{ \begin{bmatrix} \langle\text{BOS}\rangle \\ \text{LE} \\ \text{TEMPS} \\ \text{EST} \end{bmatrix} }^{\text{Decoder Input Position}} \;\Rightarrow\; \overbrace{ \begin{bmatrix} \text{LE} \\ \text{TEMPS} \\ \text{EST} \\ \text{MAGNIFIQUE} \end{bmatrix} }^{\text{Model Predicts}} = \mathbf{Y}_{\text{tgt}}Xtgt​=​⟨BOS⟩LETEMPSEST​​​Decoder Input Position​⇒​LETEMPSESTMAGNIFIQUE​​​Model Predicts​=Ytgt​

Stage 6 — Loss (Training Only)

Section titled “Stage 6 — Loss (Training Only)”

Let Y:(T, ∣V∣)\mathbf{Y} : (T,\, |\mathcal{V}|)Y:(T,∣V∣) be the one-hot target matrix, where Yik=1  ⟺  Ytgt,i\mathbf{Y}_{ik} = 1 \iff \mathbf{Y}_{\text{tgt},i}Yik​=1⟺Ytgt,i​ is token kkk and is 000 otherwise.

This defines a hard labelled distribution matrix that we can use in cross entropy loss defined in CLIP losses.

The cross-entropy loss is:

L(Xsrc,Xtgt,Ytgt)=CE(P^,Y)=−1T∑i=1T∑k=1∣V∣Yiklog⁡P^ik\mathcal{L}(\mathbf{X}_{\text{src}}, \mathbf{X}_{\text{tgt}}, \mathbf{Y}_{\text{tgt}}) = \mathbf{CE} \left( \mathbf{\hat{P}}, \mathbf{Y} \right) = -\frac{1}{T} \sum_{i=1}^{T} \sum_{k=1}^{|\mathcal{V}|} Y_{ik} \log \hat{P}_{ik}L(Xsrc​,Xtgt​,Ytgt​)=CE(P^,Y)=−T1​i=1∑T​k=1∑∣V∣​Yik​logP^ik​

Since Y\mathbf{Y}Y is one-hot, the inner sum collapses to a single non-zero term at the true token index yi=the unique k∈V:Yik=1y_i = \text{the unique } k \in \mathcal{V} : \mathbf{Y}_{ik} = 1yi​=the unique k∈V:Yik​=1

L(Xsrc,Xtgt,Ytgt)=−1T∑i=1Tlog⁡P^i, yi\mathcal{L}(\mathbf{X}_{\text{src}}, \mathbf{X}_{\text{tgt}}, \mathbf{Y}_{\text{tgt}}) = -\frac{1}{T} \sum_{i=1}^{T} \log \hat{P}_{i,\, y_i}L(Xsrc​,Xtgt​,Ytgt​)=−T1​i=1∑T​logP^i,yi​​

Gradients flow back through the decoder cross-attention, decoder self-attention, and encoder self-attention simultaneously, updating all projection matrices WQ,WK,WV\mathbf{W}^Q, \mathbf{W}^K, \mathbf{W}^VWQ,WK,WV across all layers and heads.

Inference — Autoregressive Decoding

Section titled “Inference — Autoregressive Decoding”

Inference uses the same encoder and decoder but the decoder no longer receives the full target sequence upfront. Instead it generates one token at a time, feeding each prediction back as input for the next step.

Step 1 — Encode the source once. The encoder applies all N=6N=6N=6 stacked layers in a single call:

M=Encoder ⁣(X~src,  src_pad_mask):(S,D)\mathbf{M} = \text{Encoder}\!\left(\tilde{\mathbf{X}}_{\text{src}},\; \text{src\_pad\_mask}\right) : (S, D)M=Encoder(X~src​,src_pad_mask):(S,D)

M\mathbf{M}M is computed once and reused at every generation step.

Remark — training vs inference#

During training, all T=4T=4T=4 target tokens are processed in parallel by a single decoder call (with the causal mask enforcing causality). This is what makes training efficient. During inference, the decoder is called sequentially T+1T{+}1T+1 times — each step's output token becomes part of the next step's input — since the true targets are unknown. The causal mask and the shifted-right convention together ensure that training exactly mimics the conditional dependencies seen at inference time.
